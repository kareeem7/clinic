## ♿ إمكانية الوصول (بند 30)
- **aria-*:** تمت إضافة `aria-label` (أزرار التقويم، المواعيد، المريض، الخطة، المودال)، `aria-labelledby` (المودال)، `role=dialog`، `aria-live=polite` (التنبيهات)، `aria-hidden=true` (الأيقونات الزخرفية)، `aria-current=date` (اليوم المحدد).
- **المودال:** Focus trap (Tab/Shift+Tab) + إرجاع التركيز عند الإغلاق (Escape/close) + سمات dialog.
- **الألوان:** حالات المواعيد (مؤكد/تذكير/إلغاء) صارت نصية (chip) + aria-label + اللون.
