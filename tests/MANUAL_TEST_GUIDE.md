- ✅ **رابط الموقع**: من لوحة Cloudflare → Workers & Pages → `clinic-staging` → الرابط `*.workers.dev` (أو الدومين لو مربوط). افتحه على الجهازين.

### إزاي تشوف أخطاء المتصفح (F12) — أهم مهارة هنا

1. على الكمبيوتر اضغط **F12** (أو Ctrl+Shift+I) → هيظهر جزء جنب الصفحة.
2. افتح تبويب **Console**: دور على **أي سطر أحمر**. لو لقيت سطر زي `[clinic] {requestId, context:'unmapped', code:...}` انسخه.
3. افتح تبويب **Network**: دور على طلبات لونها أحمر أو Status `4xx` / `5xx`. اضغط عليها وابعتلي الاسم والـ Status بس.
4. على الموبايل: اطلب مني أفعّل لك «USB debugging» أو ببساطة صوّر الشاشة اللي فيها الرسالة.
5. ⚠️ لو ظهر «حدث خطأ غير متوقع»: **سببه مش نقص ترحيلات** (الاتصال بالداتابيز اتظبط). دور على جلسة MFA، الشبكة، أو سطر `[clinic]` وابعتهولي — **ما تعيدش تطبيق أي SQL**.

## ٥) السيناريو الأهم: «النت قطع… رجع… اترفع كل حاجة بالترتيب»

ده اختبار طلبك الأساسي، و**لازم يتعمل على جهاز الدكتور وعلى موبايل المريض**.

**على كمبيوتر الدكتور**
1. سجّل دخول (MFA) → افتح ملف مريض «تجربة ١».
2. افصل النت فعلياً (اقفل Wi-Fi / اشيل الكابل) — أو F12 → Network → **Offline**.
3. سجّل **٣ قياسات** بأرقام مختلفة بالترتيب (مثلاً ٨٠ / ٩٠ / ١٠٠) + **صورة واحدة**.
4. **اقفل التبويب تماماً**، وافتحه تاني وهو لسه أوفلاين → لازم شريط الحالة يقول إن فيه تسجيلات معلّقة.
5. أعد النت و**ما تضغطش أي زر** → استنّى لوحده.
6. افتح قائمة القياسات: لازم تلاقي الـ ٤ عمليات **بالترتيب نفسه**، **مرة واحدة بس** (مفيش تكرار)، والشريط فاضي.

**على موبايل المريض** — نفس الخطوات من بوابة المريض، مع فصل البيانات والـ Wi-Fi من الموبايل.

**اللي تكتبه في ورقتك**: عدد العمليات اللي سجّلتها / عدد اللي ظهر بعد الرجوع / الترتيب اتغير ولا لأ / فيه تكرار ولا لأ / نص أي تنبيه ظهر.

> قيود معروفة متوقّعة (مش عيوب): أول دخول لازم بالنت · لو **مسحت بيانات المتصفح** التسجيلات المعلّقة بتضيع (فما تعملهاش وقت الاختبار) · الدفتر لكل جهاز لوحده · نسخة الدكتور الأوفلاين قراءة فقط وجزئية.

## ٦) الاختبار «البرمجي» من غير برمجة (أوامر جاهزة للنسخ)

> الأسهل: **قولّي «جري الاختبارات» وأنا بجريها هنا وأبعتلك النتيجة.** لو حابب تجربها على جهازك:

1. ثبّت **Node.js LTS** من `https://nodejs.org` (Next → Next → Install).
2. حمّل المشروع من GitHub: **Code → Download ZIP**، فكّه، وافتح **Terminal / PowerShell** جوه الفولدر اللي فيه `package.json`.
3. انسخ الأوامر دي **سطر بسطر**:

```sh
npm test
```
**المفروض يطلع بالظبط:**
```
# tests 261
# pass 261
# fail 0
```
ده معناه: ٢٦١ فحص آلي نجح (منطق الأوفلاين، التشفير، حدود الكتابة، تناسق SQL، إعداد النشر…).

```sh
node --check js/*.js sw.js
node scripts/build-edge-standalone.mjs
node --check supabase/functions/portal-photo-upload/standalone.ts
```
**المفروض:** مفيش أي كتابة خالص غير كلمة `standalone.ts rebuilt` من الأمر التاني. أي كتابة تانية = خطأ.

**لو ظهر `fail` أو كلام أحمر:** انسخ النص كامل وابعتهولي. ده كل المطلوب منك — ما تحاولش تصلّحه.

> ⚠️ **مهم جداً:** `npm test` **مش بديل** عن اختبارات القسم ٤ و٥. دي اختبارات بمحاكاة، ما بتفتحش متصفح، وما بتتصلش بالداتابيز الحقيقية، وما بترفعش صورة. الاتنين لازم يتعملوا.
