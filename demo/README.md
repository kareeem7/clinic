# عيادتي — ديمو أوفلاين (موقع جديد مستقل)

**موقع جديد تماماً في مجلد `demo/` — لم يُلمس أي ملف من الموقع القديم**
(`index.html`, `landing.html`, `css/`, `js/`, `sw.js`, `_headers`, `scripts/` كلها كما هي).

---

## ١) التنزيل والتشغيل (أسهل طريقة)

1. نزّل `clinic-demo-offline.html` (ملف واحد، ٤٤ كيلو).
2. **افتحه بدبل كليك** في أي متصفح (Chrome / Edge / Firefox / Safari).
3. خلاص. **مش محتاج** سيرفر، إنترنت، Node، npm، حساب، توكن، ولا قاعدة بيانات.

> الملف يشتغل من `file://` مباشرة لأن HTML + CSS + JavaScript + كل البيانات
> جوّه ملف واحد، بلا `<script src>` ولا `<link href>` ولا خطوط CDN ولا `fetch`.
> لو حابب تشغّله من سيرفر محلي: `bash demo/serve.sh` (أو `PORT=8090 bash demo/serve.sh`).
> السكربت بيربط على `0.0.0.0` بـ HTTP/1.1 — هو نفسه المستخدم في معاينة Arena على بورت 8081.

## ٢) اتأكد إن كل حاجة شغالة — طريقتان

### أ) من جوّه الصفحة (لا يحتاج أي شيء)
افتح تبويب **«الداتا والاختبار»** ← اضغط **«▶ اختبر كل حاجة دلوقتي»**.
المفروض يطلع **«٣٥ / ٣٥ نجح — كل حاجة شغالة ✅»** وقائمة بكل فحص.

### ب) من Terminal على جهازك (اختياري، أقوى)
```bash
node demo/verify.cjs
```
المفروض يطلع **`٢٨ / ٢٨ — كل حاجة شغالة ✅`** و`exit code 0`.
بيفحص: صياغة JS، صفر موارد خارجية/شبكة/أسرار، تطابق الأرقام مع
`sql/demo_seed_sales.sql`، كل عناصر الواجهة، والـ self-test، وتفاعلات DOM
(تبويبات، بحث، حفظ قياس، تنبيهات، تصدير، إعادة ضبط) في sandbox فعلي.

**النتيجة على الريبو وقت البناء:** `node demo/verify.cjs` → **28 / 28 ✅**،
`npm test` → أخضر، preflight → 8/8.

> ⚠️ **أمانة:** الفحوصات دي بتشغّل الـ JavaScript فعلياً في `vm` مع DOM مزيّف،
> مش في متصفح حقيقي (مفيش متصفح في بيئة البناء). عشان كده عملنا لك **بند ٣** تحت.

## ٤) إيه المش موجود عن قصد (مهم)

- ❌ أي اتصال بالخادم / Supabase / قاعدة بيانات / إنترنت / `fetch`.
- ❌ تسجيل دخول، MFA، صلاحيات، RLS، واتساب، رفع صور، طباعة.
- ❌ أسعار، اشتراكات، «١٤ يوم مجاناً»، أي وعود تجارية.
- ❌ بيانات مرضى حقيقية — **كل الأسماء والأرقام اصطناعية ١٠٠٪**.
- ❌ «النظام بيبعت إشعار للدكتور» — الصياغة الصح: القراءة **تُحفظ والدكتور يقدر يشوفها**، مش رسالة خارجية.
- ❌ ادعاء إنه تسجيل شاشة حي: دي **لقطات توضيحية** مبنية من عناصر الواجهة الفعلية.

> الداتا بتتحفظ في `localStorage` على جهازك فقط (مع fallback للذاكرة لو المتصفح مانعه).
> مفيش أي حاجة بتروح لأي سيرفر. «إعادة الضبط» بتمسح تعديلاتك وترجع البيانات الأصلية.
> لا يُستخدم في تشخيص أو علاج فعلي.
