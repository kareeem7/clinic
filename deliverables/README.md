## النسخة الحماسية (v2)
عشرة مشاهد، تعليق صوتي أغنى، ألوان وأرقام أضخم، حركة، وموسيقى خلفية خفيفة مولّدة محلياً.
تغطي: خطة المريض على الفون + «شوف بدائل» ← تسجيل السكر والضغط من البيت ← تنبيه فوري عند
قراءة تحت ٧٠ أو ضغط فوق ١٨٠/١٢٠ ← القراءة محفوظة وتظهر للدكتور ← لوحة الدكتور
«من بوابة المرضى» ← الدكتور يسجّل سكراً وضغطاً وتحاليل (CBC، HbA1c، دهون، كبد وكلى،
غدة درقية، أو مخصص) ← منحنيات السكر والضغط والوزن ← رسائل الاتجاه.

**دقة الصياغة:** الكود لا يرسل رسالة/إشعاراً خارجياً للطبيب؛ النص الفعلي هو «تم حفظها
وسيتمكن طبيبك من رؤيتها». الفيديو يقول «القراءة بتوصل للدكتور» ويوضح «مش رسالة خارجية».
متابعة السكر/الضغط تظهر حسب تفعيل العيادة للميزة.

اللقطات توضيحية من عناصر الواجهة الفعلية وليست تسجيل شاشة حي. بيانات اصطناعية، بلا أسعار.
